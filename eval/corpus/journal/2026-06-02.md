# Monday 2 June

Quiet week planned. Mostly cleanup and the search work.

## Search prototype

Spent the morning on the retrieval side of the notes tool. Current state: the
inverted index handles exact terms well and falls over on anything phrased
differently from the note. Searching for a concept in my own words returns
nothing, which is exactly the case I built the thing for.

Wired up a small embedding model and stored vectors alongside the existing full
text index in the same SQLite file. Query goes to both, results merge. Numbers
are not good yet but the failure modes are more interesting than before —
lexical search misses paraphrases, vector search happily returns something about
the wrong topic that is written in the same register. Reading up on the fusion
side, see [[vector-search]] and [[rag]].

Note to self: the index has to be keyed by the model identity. Swapping the
model without a rebuild would silently mix incompatible vectors, and the
resulting corruption would be invisible — the search just gets subtly worse.

## Cleanup

- Deleted 14 unused indexes across three services after checking `idx_scan` over

- Bumped the read timeout on the export service. The old value was shorter than
  the slowest legitimate export, which is a fun way to make a feature look
  flaky.
- Killed the last cron job still running on the old VM. That box can go.
