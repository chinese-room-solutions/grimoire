# Abbreviations

What the letters stand for, nothing more. When I actually need to decide
something the answer is in the topic note, not here.

## Kubernetes

- **HPA** — Horizontal Pod Autoscaler.
- **VPA** — Vertical Pod Autoscaler.
- **PDB** — Pod Disruption Budget.
- **PV** — PersistentVolume. **PVC** — PersistentVolumeClaim.
- **RWO / RWX** — ReadWriteOnce, ReadWriteMany.
- **CRD** — Custom Resource Definition.
- **RBAC** — Role-Based Access Control.
- **CNI** — Container Network Interface.
- **CSI** — Container Storage Interface.

## Databases and storage

- **WAL** — write-ahead log.
- **LSM** — log-structured merge tree.
- **SST** — sorted string table.
- **MVCC** — multi-version concurrency control.
- **CDC** — change data capture.
- **CQRS** — command query responsibility segregation.
- **OLTP / OLAP** — online transaction processing, online analytical
  processing.

## Reliability

- **SLI** — service level indicator. **SLO** — service level objective.
  **SLA** — service level agreement, the one with money attached.
- **RPO** — recovery point objective. **RTO** — recovery time objective.
- **MTTR** — mean time to recovery.
- **UPS** — uninterruptible power supply.

## Networking

- **MTU** — maximum transmission unit. **MSS** — maximum segment size.
- **mTLS** — mutual TLS.
- **NAT** — network address translation.
- **TTL** — time to live, which means hop count in IP and cache lifetime in
  DNS, and the two get confused constantly.
- **SNI** — server name indication.

## Machine learning

- **RAG** — retrieval-augmented generation.
- **HNSW** — hierarchical navigable small world.
- **IVF** — inverted file index. **PQ** — product quantization.
- **LoRA** — low-rank adaptation.

## Go

- **PGO** — profile-guided optimization.
- **GC** — garbage collector.
- **CGO** — the C interop layer, not an abbreviation of anything useful.

Two of these collide with the physical world and it catches me every time:
PVC is also the plastic the irrigation pipe is made of, and CDC is also the
public health agency the food-safety guidance comes from.
